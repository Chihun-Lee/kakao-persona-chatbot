# 내 말투 페르소나 만들기

본인이 쓴 글만 읽는다. 결과는 웹 도구가 쓰는 `personas/private/<id>.json` 파일이다.

## 시작 전 확인

저장소 위치(`kakao-persona-chatbot`)와 아래를 묻는다.

1. 카카오톡에서 본인으로 표시되는 이름 (여러 개일 수 있음)
2. 맞춤법을 일부러 틀려도 되는 맺음말 변형이 있는지 (예: `도윤듦`)
3. 업무방과 친구방 구분. 모르면 대화 상대 수와 존댓말 비율을 보고 제안한다.

다른 사람 말투를 만들어 달라는 요청이면 그 사람의 허락을 받았는지 먼저 묻는다. 허락이 없으면 만들지 않는다.

## 자료 모으기

| 자료 | 방법 |
|---|---|
| 카카오톡 | 방마다 대화 내보내기로 CSV를 저장한다. PC에서 여러 방을 받을 때는 화면 조작이 필요하므로 사용자 앞에서 진행한다 |
| 회사 메일 | 사용 중인 메일 도구로 보낸편지함 본문을 받아 JSONL로 저장한다 (`{"text": "..."}`) |
| Gmail | Gmail 커넥터로 `in:sent`를 검색해 본문을 JSONL로 저장하거나, Takeout의 mbox를 `--mbox`로 넘긴다 |

원본은 읽기만 한다. 이동하거나 고치지 않는다.

## 만들기

```bash
python scripts/build_persona.py --id me --name <전체 이름> --me <카톡 이름> \
  --kakao-work "<업무방>/*.csv" --kakao-friend "<친구방>/*.csv" \
  --mail-jsonl <보낸메일.jsonl> --mail-field text \
  --rare-signoff "<드문 맺음말>" --out personas/private/me.json
```

## 사람이 확인할 것

파일을 읽고 아래를 직접 고친다. 자동으로 넘어가지 않는다.

1. `typos`: 진짜 오타만 남긴다. 다른 뜻의 낱말, 일부러 쓴 말투(`~했당`), 욕처럼 읽히는 것은 지운다.
2. `examples`: 다른 사람 이름, 회사 이름, 건강과 돈 이야기, 험담이 있으면 지운다.
3. 각 채널의 `rules`: 통계와 예문을 보고 말투 규칙을 5~10줄 쓴다. 인사, 문장 길이, 끝맺음, 쓰지 않는 표현을 적는다. 이미 말투 스킬이 있으면 `--style-mail` 등으로 넘긴다.

## 시험

웹 도구를 `claude-cli` 또는 API로 띄워 아래를 확인한다.

- 보낸 적 없는 내용을 메일, 업무 카톡, 친구 카톡으로 각각 변환한다.
- 숫자와 날짜가 그대로인지 본다.
- 본인 원문과 변환문을 섞어 사용자에게 고르게 한다.

## 지킬 것

- `personas/private/`를 공개 저장소에 올리지 않는다.
- 본인 페르소나를 공개 모드에 넣을지는 사용자가 정한다. 공개하면 누구나 그 말투로 글을 만들 수 있다고 먼저 알린다.
- 원문이나 예문을 옵시디언으로 복사되는 `.md` 파일에 적지 않는다.
- 실수를 넣은 글도 사용자가 읽고 직접 보낸다. 구별되지 않는다고 약속하지 않는다.
